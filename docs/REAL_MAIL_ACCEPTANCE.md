# 真实邮箱人工验收记录

本清单必须由邮箱所有者在本机使用专门测试账户和测试邮件执行。没有真实账户授权时，所有项目保持“待人工验证”，不得把 Mock IMAP 或自动化测试填写为真实邮箱通过。

## 安全规则

- 不要把授权码、邮件正文、附件、数据库、日志原文或含完整邮箱地址的截图提交到 Git 或问题报告。
- 不要使用日常主邮箱执行批量已读；优先准备可清理的测试账户与测试邮件。
- 执行“一键已读”前必须再次核对当前范围是单账户还是统一收件箱。
- 分享日志前手工检查并遮盖邮箱地址等个人信息。应用设计上不记录授权码、正文和附件内容。

## 自动化已覆盖但不能替代真实邮箱的内容

- 多账户隔离、增量 UID 对账、UIDVALIDITY 变化、其他客户端已读对账。
- 同账户同步任务复用、账户级互斥、全局部分失败。
- 单封写回失败、本地数据库更新失败、批量 UID 部分确认、应用中断遗留状态恢复。
- IPC 输入校验、附件缓存限制及 8 种窗口尺寸的 UI 回归。

完成真实验收后，只填写观察到的实际结果。失败项应记录复现步骤、服务商、时间和脱敏错误信息，不要修改预期结果来迁就实现。
