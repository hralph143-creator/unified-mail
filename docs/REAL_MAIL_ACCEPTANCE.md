# 真实邮箱人工验收清单

此清单需要由邮箱所有者在本机执行。请勿把授权码提交到 Git、测试文件、截图或问题报告中。

## 单账户接入

分别对 QQ、163、126 执行：

1. 在服务商网页开启 IMAP 并创建客户端授权码。
2. 在应用中添加账户，先点击“测试连接”，再连接并保存。
3. 确认设置页状态为同步成功，未读数量与服务商网页一致。
4. 打开一封未读邮件详情，刷新服务商网页，确认邮件仍为未读。
5. 在应用中点击“标记已读”，确认成功提示，并在服务商网页确认该邮件已读。
6. 在服务商网页把另一封未读邮件标为已读，回到应用立即同步，确认其从未读列表移除。

## 多账户与异常

1. 同时绑定一个 QQ 与一个网易账户，确认统一未读数等于两账户之和。
2. 连续点击“立即同步”，确认只运行一个全局任务且没有重复邮件。
3. 临时断网后点击标记已读，确认应用报告失败且邮件仍显示未读；恢复网络后重试。
4. 将一个账户换成错误授权码，确认该账户提示需要重新授权，其他账户仍可同步。
5. 关闭窗口保留托盘，等待同步或用托盘菜单立即同步，确认后台功能正常。
6. 重启应用，确认账户、索引和设置仍存在；授权码不应出现在日志文件中。

测试完成后，如需分享日志，请先检查并遮盖邮箱地址等个人信息。日志设计上不记录授权码、正文和附件内容。
