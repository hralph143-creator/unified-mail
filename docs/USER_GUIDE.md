# 用户操作与故障排查

## 日常使用

统一收件箱只展示当前仍为未读的邮件。选择邮件只读取正文，不改变服务器状态；点击“标记已读”并收到成功提示后，邮件才会从列表移除。“一键已读”会处理当前账户范围；在统一收件箱使用时会处理所有账户，请只在确认范围后操作。关闭窗口默认进入托盘，托盘右键可打开窗口、立即同步或彻底退出。

设置页可以调整自动同步、同步间隔、开机启动、托盘行为、系统通知和每页邮件数量。每 6 小时自动同步的前提是电脑开机且应用仍在运行。

## QQ 邮箱

在 QQ 邮箱网页设置中开启 IMAP/SMTP 服务并生成第三方客户端授权码。服务器为 `imap.qq.com`，端口 `993`，SSL/TLS 开启。若提示授权失败，请确认使用的是授权码而非 QQ 密码，并检查服务商是否要求重新验证设备。

## 网易 163 / 126

在网易邮箱网页设置中开启 IMAP/SMTP 服务并生成客户端授权码。163 使用 `imap.163.com`，126 使用 `imap.126.com`，均为端口 `993` 和 SSL/TLS。网易可能根据安全策略限制新设备、异地网络或频繁连接；应用不会绕过这些限制。

## 常见错误

- **授权码错误、已失效，或 IMAP 服务尚未开启**：重新确认 IMAP 开关并生成新授权码，在设置页选择“重新授权”。
- **无法连接邮箱服务器**：检查互联网、代理、防火墙和服务器地址。
- **无法解析邮箱服务器地址**：检查 DNS 或自定义 IMAP 主机拼写。
- **连接超时**：稍后重试，确认网络没有拦截 993 端口。
- **证书验证失败**：不要关闭证书校验；检查系统时间、代理证书和服务器配置。
- **服务商暂时限制连接**：降低同步频率并等待服务商限制解除。
- **邮箱索引已变化**：先执行一次同步，让应用按新的 UIDVALIDITY 重建该文件夹索引。

## 本地数据

删除账户会同时删除本地加密凭据、邮件身份索引和同步关联数据，不会删除服务器邮件。清理缓存只移除本地摘要和附件临时信息，不会删除账户。下载的附件由用户选择保存位置，应用不会自动打开或执行。
