# 用户操作与故障排查

## 安装、升级与卸载

运行 `UnifiedMail-1.0.0-Setup.exe`，按向导选择当前用户的安装目录。安装版不需要 Node.js、pnpm 或其他开发环境。首次启动会在 Windows 当前用户的数据目录中创建数据库；准确位置可在“设置 → 本地数据”查看。

升级时直接运行新版安装程序并选择原安装目录。账户、加密凭据、邮件索引和设置保存在用户数据目录，不在安装目录中。默认卸载只删除程序、快捷方式和 UnifiedMail 创建的开机启动项，保留本地邮箱数据；如需清除数据，应先确认不再需要这些账户和缓存，再手工删除设置页显示的数据目录。不要在未备份时删除该目录。

安装程序当前未签名，Windows 可能显示 SmartScreen 提示。正式发布包应显示可信发布者；无法确认文件来源和 SHA-256 时不要继续安装。

## 日常使用

统一收件箱只展示当前仍为未读的邮件。选择邮件只读取正文，不改变服务器状态；点击“标记已读”并收到成功提示后，邮件才会从列表移除。“一键已读”会处理当前账户范围；在统一收件箱使用时会处理所有账户，请只在确认范围后操作。关闭窗口默认进入托盘，托盘右键可打开窗口、立即同步或彻底退出。

设置页可以调整自动同步、同步间隔、开机启动、托盘行为、系统通知和每页邮件数量。开机启动只在安装版中设置，默认关闭；启用后登录 Windows 时在托盘后台启动。每 6 小时自动同步的前提是电脑开机且应用仍在运行。系统休眠时暂停调度，唤醒后按同步间隔补偿检查。

## QQ 邮箱

在 QQ 邮箱网页设置中开启 IMAP/SMTP 服务并生成第三方客户端授权码。服务器为 `imap.qq.com`，端口 `993`，SSL/TLS 开启。若提示授权失败，请确认使用的是授权码而非 QQ 密码，并检查服务商是否要求重新验证设备。

## 网易 163 / 126

在网易邮箱网页设置中开启 IMAP/SMTP 服务并生成客户端授权码。163 使用 `imap.163.com`，126 使用 `imap.126.com`，均为端口 `993` 和 SSL/TLS。网易可能根据安全策略限制新设备、异地网络或频繁连接；应用不会绕过这些限制。

## 标准 IMAP

填写服务商提供的主机和端口。开启“直接 SSL/TLS”时从连接开始即加密；关闭时应用仍强制使用 STARTTLS，服务器不支持安全升级就会拒绝连接，不会用明文发送授权信息。当前版本只读取 `INBOX` 的未读邮件，不支持 OAuth、移动邮件或删除服务器邮件。

## 常见错误

- **授权码错误、已失效，或 IMAP 服务尚未开启**：重新确认 IMAP 开关并生成新授权码，在设置页选择“重新授权”。
- **无法连接邮箱服务器**：检查互联网、代理、防火墙和服务器地址。
- **无法解析邮箱服务器地址**：检查 DNS 或自定义 IMAP 主机拼写。
- **连接超时**：稍后重试，确认网络没有拦截 993 端口。
- **证书验证失败**：不要关闭证书校验；检查系统时间、代理证书和服务器配置。
- **服务商暂时限制连接**：降低同步频率并等待服务商限制解除。
- **邮箱索引已变化**：先执行一次同步，让应用按新的 UIDVALIDITY 重建该文件夹索引。
- **邮件已被移动或删除**：重新同步；应用不会对找不到的旧 UID 写入已读状态。
- **已读回写失败**：邮件继续保留为未读，检查网络或重新授权后再操作。

## 本地数据

删除账户会同时删除本地加密凭据、邮件身份索引和同步关联数据，不会删除服务器邮件。清理缓存只移除本地摘要和附件临时信息，不会删除账户。打开详情时应用会从邮箱服务器获取正文和附件内容用于本机显示，但不会自动把附件写入文件系统；只有用户选择保存位置并确认覆盖后才保存，也不会自动打开或执行附件。
